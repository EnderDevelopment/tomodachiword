# TomodachiWord — Minecraft Bedrock Add-on

TomodachiWord is a Minecraft Bedrock Edition add-on inspired by the Tomodachi Life game for the Nintendo 3DS. This add-on introduces a spawn egg that summons a talking character who guides the player through an interactive tutorial, including building a house, naming a city, and creating a custom Mii character. The add-on features scripted dialogue, UI menus for city naming and Mii creation, and background music, bringing a Tomodachi Life experience to your Minecraft world on Android or other Bedrock platforms.

## Install

1. Download the `TomodachiWord.mcaddon` file to your device.
2. Open the file with Minecraft (on Android, tapping the file will prompt you to open it with Minecraft).
3. Minecraft will automatically import the add-on.
4. Create a new world or edit an existing one.
5. In the world settings, activate the following **Experimental** toggles:
   - `Beta APIs`
   - `Holiday Creator Features` (if available)
   - `Molang Features` (if available)
6. Save the world and enter it.

## Use

1. In the game, open the chat and type `/function tomodachi:start` (requires operator permissions or cheats enabled).
2. You will receive a **Tomodachi Spawn Egg**.
3. Right-click or tap on a block while holding the egg to summon the Tomodachi character.
4. The character will start the tutorial dialogue in the chat.
5. Follow the prompts to name your city and create your Mii.
6. Use the following commands to access specific features:
   - `/function tomodachi:city_name` — Opens the city naming menu.
   - `/function tomodachi:mii` — Opens the Mii creation menu.
   - `/function tomodachi:music` — Activates the background music.
   - `/function tomodachi:end` — Resets the tutorial.
   - `/give @s tomodachi:egg` — Gives you the spawn egg directly.
